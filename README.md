# tea-panel-ui

Веб-интерфейс для оценки вкусов в рамках проекта [tea-tests](https://github.com/taste-systems/tea-tests).

## 📌 Назначение

Это клиентская часть (frontend) дегустационной панели. Пользователи оценивают чай по ряду параметров с помощью радиальной (лучевой) диаграммы и ползунков.

## 🔧 Технологии

- React + Vite
- UI-компоненты: [shadcn/ui](https://ui.shadcn.com/)
- Адаптирован для мобильных устройств

## 📦 Статус

🔬 Этап тестирования и доработки интерфейса. Возможны изменения.

---

Этот репозиторий не содержит серверной логики — только веб-интерфейс.
